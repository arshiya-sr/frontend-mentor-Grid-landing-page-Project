### The challenge

Users should be able to:

- View the optimal layout for the page depending on their device's screen size
- See hover and focus states for all interactive elements on the page
- Open and close the navigation menu at any screen size (optional JavaScript)

### What I learned

In this project, I learned:

- How to work with GitHub Desktop.
- How to build a hamburger menu myself, without relying on AI, and without JavaScript, in two different layouts for desktop and mobile.
- How to build attractive and beautiful structures with grid.
- How to manage and move the project forward in a more professional way.
